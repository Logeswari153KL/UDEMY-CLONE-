# UDEMY-CLONE-
A creative and responsive Udemy Clone built using HTML and CSS. Includes a custom navbar, search bar, categories, course cards with hover effects, banner section, and a clean UI with a modern layout. Designed uniquely while following Udemy’s structure. Fully responsive and beginner-friendly.

🌐 Personal Portfolio Website

This is my personal portfolio website created using HTML and basic CSS. It showcases my skills, projects, and contact details in a simple, clean, and responsive layout. The main goal of this project is to build a professional online presence and practice core web development concepts without using external libraries or frameworks.

🔧 Features

Clean and minimalistic UI

Fully responsive layout using only HTML & CSS

Sections included: Home, About, Skills, Projects, and Contact

Simple hover effects and smooth user experience

Easy-to-edit structure for future improvements

🛠️ Technologies Used

HTML5 – Structure of the website

CSS3 – Styling, layout, and basic animations
